================================================================================
RELOOP UI LAYOUT & DESIGN SYSTEM CONFIGURATION (DESKTOP & MOBILE)
================================================================================

--------------------------------------------------------------------------------
1. RESPONSIVE BREAKPOINTS & VIEWPORT CONTAINMENT
--------------------------------------------------------------------------------
- Sticky Sidebar Preservation: `html` & `body` must NOT use `overflow-x-hidden` (which breaks CSS `position: sticky` on ancestor elements).
- Viewport Containment: Placed on right content column `<div className="flex min-h-screen min-w-0 flex-1 flex-col overflow-x-hidden">`
- Main Wrapper: `<main className="w-full min-w-0 max-w-full flex-1 px-4 pb-24 pt-6 md:px-8 md:py-8">`
- Mobile Viewport:  < 768px (uses md:hidden classes for mobile UI elements)
- Desktop Viewport: >= 768px (uses md:flex, md:block, md:px-8 classes)

--------------------------------------------------------------------------------
2. LANDING & PUBLIC HEADER (frontend/src/components/layout/PublicLayout.jsx)
--------------------------------------------------------------------------------
- Brand Logo + Title: Top-left
- Nav Links: How it works, Pricing, Impact, FAQ, Contact
- Right Action Group:
  * Theme Toggle Button (`h-9 w-9`, Sun/Moon icon) positioned directly BEFORE "Sign in" / "Go to dashboard"
  * Mobile Top Header: Includes Theme Toggle Button (`h-9 w-9`) beside hamburger menu button

--------------------------------------------------------------------------------
3. MOBILE CHART RESPONSIVENESS (useIsMobile & Recharts)
--------------------------------------------------------------------------------
- Responsive Hook: `useIsMobile(640)` in `frontend/src/hooks/useIsMobile.js`
- Card Container Padding: `p-3.5 sm:p-5` (prevents clipping chart canvas on small screens)
- Container Heights: `h-56 sm:h-64` (Pie charts) | `h-64 sm:h-80` (Area & Bar charts)
- Pie Chart Labels:
  * Mobile (<640px): `label={false}`, `innerRadius={35}`, `outerRadius={65}` (relies on responsive status badge grid below)
  * Desktop (>=640px): Outer text labels enabled (`label={({ status, count }) => ...}`), `outerRadius={80}`
- Y-Axis & X-Axis Ticks:
  * Mobile (<640px): `fontSize={9}`, vertical bar chart YAxis `width={85}`
  * Desktop (>=640px): `fontSize={11}`, vertical bar chart YAxis `width={125}`
- Chart Margins: Negative left margins on mobile (`left: -20` / `left: -15`) to align Y-axis numbers against card borders.
- Legend Styling: `iconSize={8}` with `wrapperStyle={{ fontSize: isMobile ? 10 : 12 }}`.

--------------------------------------------------------------------------------
4. APP SHELL LAYOUT CONFIGURATION (frontend/src/components/layout/AppShell.jsx)
--------------------------------------------------------------------------------

A. TOP HEADER (Sticky, z-index: 20)
   - Background: bg-white/90 backdrop-blur-md border-b border-ink/10
   - Padding: px-4 py-3 (Mobile) | md:px-8 (Desktop)
   - Left Side:
     * Mobile: BrandMark logo + "Reloop" text (hidden on desktop)
     * Desktop: Role indicator label (e.g. "Consumer Portal", "Admin Console")
   - Right Side (Action Bar):
     1. AI Chat Button: rounded-full bg-circuitlight/40 (Text hidden on mobile, visible on desktop)
     2. Desktop Theme Toggle Button (`hidden md:flex` ONLY):
        - Position: BETWEEN AI Chat button and Notification Bell
        - Size: h-9 w-9 (Matches Notification Bell size)
        - Icon: Sun icon when dark mode active, Moon icon when light mode active
     3. NotificationBell: Unread notifications counter badge & popover menu (Size: h-9 w-9)
     4. Mobile Sign Out Button (`md:hidden` ONLY):
        - Position: Top-right beside NotificationBell
        - Size: h-9 w-9 (Exactly matches NotificationBell size)
        - Styling: rounded border border-ink/10 bg-white text-ink hover:border-brick/30 hover:bg-brick/5
        - Icon: 17x17 logout icon

B. DESKTOP SIDEBAR (Sticky, z-index: 10, hidden below md)
   - Sticky Positioning: `sticky top-0 h-screen` (anchors to window top on desktop)
   - Width: w-60 (240px)
   - Border: Right border border-ink/10 bg-white
   - Header: BrandMark logo + "Reloop" brand name
   - Navigation Items: Vertical stack with active background `bg-circuitlight text-circuitdark`
   - Footer:
     * User Full Name + Role Label
     * Desktop Sign Out Button (btn-ghost with settings icon, full-width)

C. MOBILE BOTTOM NAVIGATION BAR (Fixed bottom, z-index: 30, hidden on desktop)
   - Max Direct Items: 5 (MAX_BOTTOM_BUTTONS)
   - Overflow Behavior: If > 5 nav items, first 4 are shown directly, 5th slot becomes "Menu" button
   - Safe Area: paddingBottom env(safe-area-inset-bottom)
   - Active Color: text-circuitdark | Inactive: text-inkfaint

D. MOBILE OVERFLOW DRAWER / MENU SHEET (z-index: 40)
   - Triggered by "Menu" button in bottom bar
   - Sheet Style: Rounded-t-lg bg-white shadow-stamp animate-rise
   - Max Height: max-h-[85vh] scrollable
   - Contains:
     * Remaining navigation links
     * User name & role label
     * Mobile Theme Toggle Button (Size: h-9 w-9, Sun/Moon icon)
     * Mobile Sign out button

--------------------------------------------------------------------------------
5. THEME CONTEXT & STYLING (frontend/src/context/ThemeContext.jsx & index.css)
--------------------------------------------------------------------------------
- Persistent Theme State: Stored in localStorage under `reloop_theme` ("light" | "dark")
- Root Class: Adds `.dark` class to `document.documentElement` (`<html>`)
- Dark Theme Colors:
  * Paper background: #0E1612
  * Card / Header background: #15201B
  * Secondary container background: #1A2822
  * Primary text (`text-ink`): #E6EFEA
  * Muted text (`text-inkfaint`): #8CA095
  * Border stroke: rgba(230, 239, 234, 0.12)
